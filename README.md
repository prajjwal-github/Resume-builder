# 📝 ResumeAI – Resume Builder Web App

ResumeAI is a modern, responsive web application that allows users to easily create professional resumes through an intuitive and interactive interface. Users can sign up, log in, fill in their resume details, and see a live preview of their resume while editing.

---

## 🚀 Features

- **User Authentication**  
  - 🔐 Login & Signup pages for account management  
  - 🔄 Secure session handling

- **Home Page**  
  - 👋 Introduction to the app and its benefits  
  - 📌 Highlights key features like templates, live preview, and PDF export  

- **Resume Builder Page**  
  - 🧩 Multi-step form for personal details, education, experience, skills, etc.  
  - 👀 Real-time **live preview** of the resume on the same page  
  - 💾 Auto-save functionality for convenience (optional)  
  - 🖨️ Option to export final resume as PDF

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript  
- **Animations:** CSS & JS-based transitions  
- **Validation:** JavaScript form validation  
- **PDF Export:** (e.g., `html2pdf.js` or `jsPDF`)  
- **(Optional)** Backend for login/signup and data persistence (Node.js, Firebase, etc.)
